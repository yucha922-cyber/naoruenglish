# セラピストの英会話 | naoruenglish

整体院・セラピストのための実用英会話サイトです。
外国人の患者様が来院されたときに、**その場で開いてすぐ使える**ことを第一に作っています。

収録数：会話フレーズ 1,054（うち「気軽な言い換え」142）・単語 209・筋肉名 69・症状別 12・会話シナリオ 9・オンライン英会話 8場面＋通し台本

> **公開URL**（GitHub Pages 有効化後）
> https://yucha922-cyber.github.io/naoruenglish/

## 何ができるか

### 1. 施術の流れに沿ったフレーズ集

実際の施術の順番どおりに並んでいます。迷わず目的のフレーズにたどり着けます。

| ステップ | 内容 |
|---|---|
| 0. お電話対応 | 受け答えの基本・予約・変更とキャンセル・道案内・料金の問い合わせ・症状のご相談 |
| 1. 来院時の挨拶 | 出迎え・予約確認・問診票のご案内・施術室へのご案内 |
| 2. 問診・聞き取り | 主訴・発症時期・**これまでの治療歴**・痛みの性質と強さ・**動作によるスクリーニング（体幹／首／肩）**・生活習慣・**安全確認（禁忌）** |
| 3. お身体のチェック | 検査の同意・姿勢確認・可動域チェック・体位指示・触診中の声かけ |
| 4. 状態のご説明 | 筋肉と姿勢の状態・原因の説明・理解確認・医療機関のご案内 |
| 5. 施術プランのご提案 | 施術内容・**圧の好み・強さの確認**・施術後の注意・セルフケア指導・通院プラン・会計 |

各ステップには**患者様が言いそうな英語**を場面別に収録しています（「主訴を伝える」「痛みの様子」「これまでの治療」「動作確認のとき」など）。
同じ内容でも人によって言い方が違うため、`killing me` `slept funny` `acting up` のようなくだけた言い方も載せています。

**「こんな言い方もOK」** — 堅くなりがちなフレーズには、同じ意味の気軽な言い方を併記しています。
例：`What brings you in today?` → `What brings you here today?` / `How can I help you today?` / `What's going on today?`

**スクリーニング（問診編）** — 前屈・後屈・回旋・側屈（体幹）、首の前屈・後屈・回旋・側屈、肩の挙上・外転・すくめ、結帯動作・結髪動作の指示と、動作中の確認（「どこに感じますか」「脚まで響きますか」）をまとめています。

### 2. お電話対応（6場面・209フレーズ）

電話は相手の口元が見えず身振りも使えないため、現場より難しい場面です。

- **聞き取れないときの逃げ道** — 「お電話が少し遠いようです」など、自分のせいにせず聞き返せる言い方
- **名前と電話番号の確認** — つづりの確認、`B as in boy` の使い方、復唱のしかた
- **予約・変更・キャンセル・遅刻** — キャンセルされても角が立たない受け方
- **道案内** — 日本の住所は電話で伝わりません。最寄り駅・目印・地図リンクの3点で解決します
- **症状のご相談** — 電話では診断できないため、断定を避けつつ受診をすすめる伝え方

### 3. オンライン英会話の練習会（8場面＋通し台本）

2週間に1回のオンライン練習会で、入室から退出まで通して使えるテンプレートです。

> **管理者専用のページです。** 管理者のアカウントでログインしているときだけ、ホーム・学習タブ・検索・練習範囲に表示されます。それ以外の人が `#/meeting` を開くと「ページが見つかりません」と表示されます。

| 場面 | 内容 |
|---|---|
| 1. 入室・最初のあいさつ | 第一声・遅れて入ったとき・途中で抜けるとき |
| 2. 音声・画面のトラブル | 聞こえない・ミュート・固まった・画面共有・チャット |
| 3. 近況・雑談 | 2週間ぶりの近況・患者様の話題 |
| 4. 今日の進め方 | 司会のフレーズ・順番と時間配分・休憩 |
| 5. ロールプレイ | 役を決める・止める・やり直す・言葉が出ないとき |
| 6. 聞き返す・確認する | 聞き取れない・意味を聞く・チャットで書いてもらう |
| 7. フィードバック | ほめる → 提案する・振り返り |
| 8. 次回の予定・退出 | 宿題・次回の日程・退出のあいさつ |

**通しの台本**では、自分（A・司会）と相手（B）の会話を入室から退出まで1回分並べています。そのまま読み合わせに使えます。

### 4. 症状別の会話（12症状）

肩こり／腰痛／首こり／猫背／巻き肩／反り腰／背中の痛み／頭痛／めまい／股関節の痛み／膝の痛み／捻挫

症状ごとに以下をまとめています。

- **英語での言い方の注意** — 「猫背」を `cat back` と言っても通じない、`hunchback` は侮辱的に響く、腰は `waist` ではなく `lower back`、など現場で失敗しやすいポイント
- 患者様の表現／その症状特有の問診／状態の説明／関連する筋肉／セルフケア指導
- **施術を控えて受診をおすすめするサイン（レッドフラッグ）**

### 5. 単語集・筋肉の英語名

- 身体の部位・痛みの表現・動作の指示・施術と手技・時間と頻度・受付と会計・安全と注意事項・雑談の8カテゴリ209語
- 主要筋肉69件を部位別に。英語名・日本語名・**カタカナ発音の目安**・作用つき

### 6. 学習機能

- **クイズ** — フレーズ／単語／筋肉名から4択で10問。**答えた直後に解説カード**が開き、正解の英文・訳・使う場面・文中の重要語の意味が出ます。ふつう／ゆっくりの2速度で聞き直せ、その場で復習リストにも入れられます。**不正解だった3つの選択肢にも同じ解説と音声が付く**ので、1問で4つとも覚えられます
- **発音練習** — 手本を聞いて声に出すと、音声認識が単語単位で判定します。話し終わるまで自動では止まらないので、ゆっくり区切って話しても大丈夫です
- **会話シミュレーション** — 電話4本＋施術5本の計9シナリオ。3択の返答に一つずつ解説がつきます

**3つとも「練習する範囲」を選べます。** 「電話の予約変更だけ」「問診だけ」「頭痛だけ」のように、覚えたいパートに絞って練習できます。
各フレーズ集のページ下部にある「このパートを練習する」から、読んだ内容をそのまま練習に持ち込めます。

### 7. 現場で効く小さな工夫

- すべてのフレーズに**読み上げボタン**。発音に自信がなくても、押せば伝わります
- **拡大表示ボタン** — 画面を患者様に向けて見せられます
- **お気に入り（★）** — よく使うフレーズを集めて、発音練習の題材にもできます。ログインするとアカウントに保存され、別の端末でも使えます。フレーズの英文を言い換えても、お気に入りは自動で引き継がれます
- **日本語でも英語でも横断検索**
- 読み上げの速さと音声は設定から変更できます（患者様に聞かせるときは 0.8〜0.9 が聞き取りやすい速さです）

## 動作環境

| 機能 | 対応状況 |
|---|---|
| フレーズ閲覧・検索・クイズ | すべてのモダンブラウザ |
| 読み上げ | Web Speech API 対応ブラウザ（iOS Safari / Android Chrome / PC 各種） |
| 発音の判定 | Google Chrome・Safari（マイクの許可が必要です） |

音声認識に対応していない端末では、その機能だけが自動で無効になります。他の機能は問題なく使えます。
学習の記録は端末内（localStorage）に保存されます。
ログイン機能を有効にした場合のみ、ログインに使った Gmail アドレス・利用日時・閲覧中のページ・お気に入りが Firebase（Google のサービス）に保存されます。

## ログインと管理画面の設定

Google アカウントでのログインと、**管理者だけが見られる管理画面**（`#/admin`）を用意しています。
管理画面では、いまサイトを開いている人・ログインしたことのある人・ログイン履歴を Gmail アドレスで確認できます。

設定しないうちは、これまでどおりログインなしで誰でも使えます。

### 1. Firebase プロジェクトを作る（無料枠で足ります）

1. https://console.firebase.google.com/ で「プロジェクトを追加」
2. **Authentication** › 始める › ログイン方法 › **Google** を有効にする
3. Authentication › 設定 › **承認済みドメイン** に `yucha922-cyber.github.io` を追加する
4. **Firestore Database** › データベースを作成（本番モード・リージョンは `asia-northeast1` など）
5. プロジェクトの設定 › マイアプリ › ウェブアプリ（`</>`）を追加し、表示された `apiKey` `authDomain` `projectId` `appId` を控える

### 2. サイト側の設定

- `js/config.js` の `firebaseConfig` に、控えた4つの値を貼り付ける
- 同じファイルの `ADMIN_EMAILS` に、管理者の Gmail アドレスを書く
- `REQUIRE_LOGIN` を `true` にすると、ログインしないとサイトを閲覧できなくなります（誰が使っているかを把握するにはこちら）

> `apiKey` などの値は公開されても問題ない種類のものです。データの保護は次のセキュリティルールで行います。

### 3. セキュリティルールを設定する（必須）

1. `firestore.rules` の `adminEmails()` に、管理者の Gmail アドレスを書く
2. Firebase コンソール › Firestore Database › **ルール** に、ファイルの中身を貼り付けて「公開」

これで、利用者一覧とログイン履歴は**管理者のアカウント以外からは読み取れなくなります**。
管理画面はメニューにも表示されず、管理者以外が `#/admin` を開いても「ページが見つかりません」と表示されます。
管理者でログインしているときだけ、⚙️ 設定 › アカウント に「🔒 管理画面」ボタンが出ます。

### 注意

- LINE などのアプリ内ブラウザでは Google ログインが使えません。Safari や Chrome で開くよう案内してください（ログイン画面にも自動で表示されます）
- リポジトリが公開（Public）の場合、サイトのソースコード自体は GitHub 上で誰でも見られます。ログインは「誰が使っているかを把握する」ための仕組みです

## ローカルでの動かし方

ES モジュールを使っているため、ファイルを直接開くのではなく簡易サーバー経由で開いてください。

```bash
git clone https://github.com/yucha922-cyber/naoruenglish.git
cd naoruenglish
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

ビルドも依存パッケージも不要です。

## 内容を追加・修正するには

`js/data/` 配下のファイルだけを編集すれば、画面には自動で反映されます。
たとえばフレーズを1つ増やす場合は、該当のグループに1行足すだけです。

```js
{ en: 'Does this hurt?', ja: 'ここは痛いですか。', note: '最も使う一言。' }
```

`note` は省略できます。症状・筋肉・単語も同じ形式です。

気軽な言い換えを添えるときは `alts` を足します。

```js
{ en: 'What brings you in today?', ja: '今日はどうされましたか。', alts: ['How can I help you today?'] }
```

**すでにある英文を書き換えるときは、`js/data/renamed.js` に「旧 → 新」を1行追加してください。**
お気に入りは英文をキーに保存しているため、登録しておくと全員のお気に入りが自動で新しい英文に引き継がれます。

## ご利用にあたって

本サイトは**整体・セラピストの語学学習および接客支援**を目的としています。

- 整体は医療行為ではありません。掲載された表現で**診断を行うことはできません**
- 各症状ページの「受診をおすすめするサイン」に該当する場合は、施術を行わず医療機関の受診をご案内してください
- 掲載内容は一般的な情報であり、個別の症例に対する医学的助言ではありません
